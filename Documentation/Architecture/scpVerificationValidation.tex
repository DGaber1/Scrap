\noindent This chapter defines how the team will confirm that Scrap is built correctly and that it solves the problem it set out to solve. Verification asks whether the system conforms to its own specification --- \textit{did we build the system right} --- and is checked per requirement through inspection, demonstration, test, or analysis \cite{IEEE1012}. Validation asks whether the completed system meets real stakeholder needs in its intended context --- \textit{did we build the right system} --- and is checked through realistic usage scenarios with actual users \cite{IEEE1012}. Because Scrap has not yet been built, every status below is \StatusPending; the team will update this chapter as the \hyperref[Chapter:DevelopmentPlan]{Development Plan} chapter's Testing Plan is carried out, and validation in particular will not be meaningful until beta users are recruited in January 2027 (see that chapter's Timeline and Milestones).
